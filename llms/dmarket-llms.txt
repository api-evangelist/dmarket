# DMarket

> DMarket is a marketplace for trading in-game items and skins (CS2, Dota 2, TF2, Rust) with a public JSON Trading API for programmatic inventory management, buying, selling, and price discovery. Every request is authenticated with a public API key and an Ed25519 request signature.

## APIs

- [DMarket Trading API (Swagger)](https://docs.dmarket.com/v1/swagger.html): Manage inventory, buy/sell offers, place buy targets, deposit/withdraw assets, and read sales history. Base URL https://api.dmarket.com.

- [OpenAPI 3.0.4](https://raw.githubusercontent.com/api-evangelist/dmarket/refs/heads/main/openapi/dmarket-trading-openapi.yml): DMarket Trading API v2.0.0, 22 operations.
